# Pronunciation gap evidence

`review.json` records seven disagreements found by the frozen HKCanCor evaluation. It is separate from the existing frozen `data/review-v2` pack. No extra lexicon source is selected by this file.

Each record preserves source tokens and coordinates, selected-case occurrences, separately counted full-corpus aligned occurrences, retained raw source rows, cited primary evidence and an explicitly provisional assessment. Generated phrase readings are excluded from attestations. Counts do not measure independent speakers. One-to-one character alignment is mechanical and does not establish linguistic decomposition.

All seven `review_status` fields are `pending`; reviewer, date, evidence and approved-action fields are blank. Any later filled field is a review claim, not authenticated approval. Do not edit generated evidence to make it agree with a proposed decision; record decisions separately and retain the original hashes.

Source attribution and reuse boundaries are attached to each evidence item. HKCanCor excerpts credit K. K. Luke and May L. Y. Wong, hosted by Francis Bond, under the retained CC BY 4.0 license. Public-domain words.hk wordlist data is distinct from its noncommercial dictionary definitions/examples. The latter and CUHK/MOE references were not imported into the default dictionary.

See [the written review](../../docs/PRONUNCIATION_GAP_REVIEW.md) for findings, limitations and questions that still require linguistic judgment. Existing evaluation scores, source labels, dictionary and approval gates remain unchanged.
