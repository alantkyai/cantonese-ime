The fixed C9 global initial-character change did not improve reported proper or habitual first-nine/first-90 coverage over C8. It failed the same original gate: habitual first-nine coverage was 26/29, below the required 27/29. All 402 fresh forms completed cleanly. Independent reconciliation verified all 14 gates; quality passed 13. C9 was rejected and stopped; no retuning or later learned-profile, external, controlled-latency, integration or native stage followed.

C9 changes only the previous=None character probability to `P0(c)=(Cu(c)+10L(c))/(1379235+10)`, charged once for the first emitted character of a complete composition. `Cu` is the unchanged global curated character count and `L` the unchanged lexical marginal, including one unknown bucket with curated count zero. This is a global composition-initial marginal, not a model trained on BOS positions or natural usage frequency. Every non-None previous class, including unknown 0, delegates exactly to C8. The [curated experiment](CURATED_CONTEXT_EXPERIMENT.md) records the reused source/card/license and ownership qualifications.
