The original isolated experiment under `.local/cccedict-candidate` is retained
as historical evidence. Its measurements and hashes below describe that
headword-only intermediate, before the explicit Yue supplement.

The pinned CC-CEDICT snapshot supplies traditional and simplified **written
forms only**. Its Mandarin Pinyin and definitions supply no Cantonese readings.
New readings are generated by the existing bounded Cantonese ScriptAutoencoder
using the frozen baseline's permitted explicit character translations. The
selected components exclude Unihan, the earlier CCCanto/CC-CEDICT Cantonese
supplements, and Cantonese Wordnet from translator inputs, following the
baseline's recorded policy. The new generated rows never feed the translator.

## Canonical selection and v3 mapping

Two normal-default builds completed successfully with identical database bytes
and manifest SHA-256
`60532631e6790299e4e30145b99b8ad201b826112a58596f5a6ac5cd97994a08`.
Their full entry/ID and ledger contents match the combined isolated candidate;
only indentation in six SQL table declarations differs from that intermediate.
All 739,128 earlier Wordnet rows and IDs remain. The headword phase still adds
exactly 36,884 generated pairs for 21,038 texts using the unchanged translator
cohort. The later Yue source contributes 323 explicit pairs and 166 new texts;
its readings do not feed either autoencoder.

Independent read-only checks passed on both raw builds: all 250,590 written-form
occurrences, all 21,142 recomputed headword encodings, and all 36,884 generated
rows match. The independent Yue audit also matches all 1,486 explicit pairs and
the complete 11,396-page / 19,804-section / 5,366-field / 647-review ledgers,
crediting only its 323 new owned rows after every check succeeds. These checks
establish source/algorithm correspondence, not pronunciation approval.

The published `cantonese-yale-ascii-v3` profile preserves primary spellings and
adds six independently sourced whole-syllable alternatives: `deeu`, `eeu`,
`meeu`, `peeu`, `seeu`, `jeeu` for canonical `deu`, `eu`, `meu`, `peu`, `seu`,
`zeu`. KFCD's pinned numeric-Yale table supplies their evidence; its marginal
`hm` and `hng` attestations are classified as extensions. `ngm` and `soei` remain
explicit Jyutping fallbacks. Strict Jyutping is unchanged. Neither this source
selection nor these spelling routes certify all Chinese vocabulary or ranking.
